# Sorour Mohamed — Personal Portfolio & Admin Dashboard

موقع شخصي متكامل + لوحة تحكم إدارية (Admin Dashboard) لـ **Sorour Mohamed — Creative Production Studio**، يدعم العربية (RTL) والإنجليزية (LTR)، والوضع الداكن (Dark Mode) والفاتح (Light Mode)، ومتجاوب بالكامل مع الهاتف والتابلت والكمبيوتر.

---

## 1. التشغيل المحلي (Local Setup)

المشروع مبني بـ **Python 3.11+ و SQLite** بدون أي مكتبات خارجية مطلوبة في الخادم (`pip install` غير مطلوب).

```bash
# 1. انسخ ملف البيئة وعدّل القيم
cp .env.example .env

# 2. عيّن بريد وكلمة مرور أولية للمسؤول (أو اتركها فارغة لتوليد كلمة مرور عشوائية تُطبع مرة واحدة)
export ADMIN_EMAIL="your-email@example.com"
export ADMIN_PASSWORD="YourStrongPassword!2026"

# 3. شغّل الخادم (يقوم تلقائياً بتنفيذ migration 001_init.sql وتعبئة البيانات الأولية)
python3 server.py
```

افتح المتصفح على:
- الموقع العام: `http://localhost:8080`
- لوحة التحكم الإدارية: `http://localhost:8080/#/admin`

> **تنبيه أمني مهم:** بعد أول تسجيل دخول في لوحة التحكم، ادخل على **الإعدادات / تغيير كلمة المرور** وغيّر كلمة المرور الأولية فوراً.

---

## 2. تشغيل الاختبارات التلقائية (Automated Tests)

```bash
python3 -m unittest discover -s tests -v
```

تغطي الاختبارات:
- تسجيل الدخول ورفض كلمات المرور الخاطئة وحماية مسارات الإدارة.
- نظام الصلاحيات (**Super Admin** / **Editor** / **Viewer**) والتأكد من منع الـ Viewer من التعديل أو الحذف أو تصدير الطلبات.
- دورة حياة المشاريع (مسودة `draft` لا تظهر للزوار ← نشر `published` تظهر فوراً في الموقع).
- نموذج طلبات العملاء + حقل الحماية من السبام (`honeypot`) + الملاحظات الداخلية + تصدير CSV.
- التحقق من الملفات المرفوعة عبر البايتات الفعلية (`Magic Bytes`) ومنع حذف وسائط مستخدمة في مشروع منشور.
- سجل النشاط (`Audit Log`).

---

## 3. النشر الفعلي (Production Deployment)

1. ارفع مجلد المشروع على خادم VPS (Ubuntu) أو منصة تدعم Python (مثل Railway / Render / Fly.io).
2. اضبط متغيرات البيئة من `.env.example` في إعدادات الاستضافة (لا ترفع ملف `.env` إلى Git).
3. اربط دومينك مع شهادة **HTTPS** (مثلاً عبر Nginx + Let's Encrypt أو Cloudflare).
4. **النسخ الاحتياطي (Backup):** انسخ ملف قاعدة البيانات `data/portfolio.db` ومجلد `uploads/` بشكل دوري (أسبوعياً أو يومياً).

---

## 4. تقرير الجاهزية والخدمات الخارجية

### مكتمل ويعمل فعلياً:
- الموقع العام بالكامل (الرئيسية، من نحن، الخدمات وتفاصيلها، معرض الأعمال وتفاصيل المشاريع، تواصل معنا، سياسة الخصوصية، الشروط والأحكام، صفحة 404).
- لوحة تحكم إدارية كاملة (نظرة عامة + رسم بياني، إدارة المشاريع والوسائط، إدارة الخدمات، إدارة طلبات العملاء + ملاحظات داخلية + تصدير CSV، محرر محتوى الصفحات CMS بالعربية والإنجليزية، مكتبة الوسائط، إدارة المستخدمين والصلاحيات، الإعدادات، وسجل النشاط).
- تبديل كامل للغة (AR/RTL ↔ EN/LTR) والمظهر (Dark ↔ Light) مع الحفظ التلقائي.
- قاعدة بيانات SQLite بجميع الجداول الـ 11 + `robots.txt` + `sitemap.xml`.

### يحتاج إعداد خارجي أو مفاتيح من صاحب المشروع:
- **إشعارات البريد الإلكتروني (SMTP):** أضف قيم `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS` في `.env` لتفعيل إرسال بريد تنبيهي عند وصول طلب جديد أو استعادة كلمة المرور.
- **التحليلات والتتبع:** أضف `GA_MEASUREMENT_ID` و `META_PIXEL_ID` في الإعدادات عند الجاهزية.
- **الصورة الشخصية والمشاريع الحقيقية:** المشاريع المبدئية (`Al Andalus Coffee` و `Clear Eyewear`) محفوظة كـ **مسودات** في الخادم؛ ارفع صورك وفيديوهاتك الحقيقية ورقم الواتساب من لوحة التحكم ثم انشرها.

## 5. عرض الموقع عبر GitHub Pages
تم تجهيز `index.html` في جذر المستودع كمدخل للواجهة الثابتة. GitHub Pages يعرض الواجهة الأمامية فقط؛ فهو لا يشغّل خادم Python أو قاعدة بيانات SQLite. لتشغيل ميزات الخادم وواجهات API، انشر المشروع على استضافة Python مع إعداد متغيرات البيئة والتخزين الدائم كما في الأقسام أعلاه.
